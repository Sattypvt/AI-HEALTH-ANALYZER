# 🩺 AI Health Analyzer

An AI-powered **Multi-Disease Health Risk Prediction System** built using Machine Learning and Flask.  
The application analyzes user health parameters and predicts the risk of:

- ❤️ Heart Disease
- 🩸 Diabetes
- 💉 Hypertension

It also generates an overall **Health Score** and provides risk insights based on medical indicators and symptoms.

---

## 🚀 Features

✔️ Multi-disease prediction  
✔️ Machine Learning based risk analysis  
✔️ Health score calculation (0-100)  
✔️ Symptom-based risk adjustment  
✔️ Emergency risk alerts  
✔️ User-friendly web interface  
✔️ Prediction history storage  

---

## 🧠 Machine Learning Model

The system uses a **Random Forest Classifier** trained on health parameters.

### Input Features

- Age
- BMI
- Blood Pressure
- Glucose Level
- Cholesterol Level
- Smoking Status
- Symptoms

### Predictions

The model predicts probability scores for:

- Heart Disease Risk
- Diabetes Risk
- Hypertension Risk
